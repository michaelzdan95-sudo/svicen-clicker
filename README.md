# svicen-clicker
## Svícens Clicker

A clicker game made with React and Vite. It is deployed to GitHub Pages by `.github/workflows/pages.yml`.

Run it on a computer:

    npm install
    npm run dev

The files in `public/` (`svicen-choral.mp3`, the `.mp4` video and `plane-banner.png`) are placeholders. Replace them with your own, using the same file names.
